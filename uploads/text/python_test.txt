1. Dictionary & String Processing – Word Frequency Counter
Write a function that takes a sentence as input and returns a dictionary where each word is a key, and its value is the number of times it appears in the sentence. Ignore capitalization and punctuation.

Hint:
Use .split() to break the sentence into words.
Convert words to lowercase for uniformity.
Use a dictionary to store counts.
Example Input:
sentence = "Hello world! Hello everyone."

Expected Output:
{"hello": 2, "world": 1, "everyone": 1}
